## ✨ Features

- 📁 **Telegram MTProto Storage**: Seamlessly upload files directly into your Telegram account's cloud storage (up to 2GB per file).
- ⚡ **Instant File Streaming**: Stream audio, video, and image previews directly through high-speed Telegram stream proxies.
- 🗂️ **Nested Folders & Hierarchy**: Organize files into virtual folders, subfolders, and category views (Photos, Videos, Audio, Docs).
- 🔍 **Real-Time Search & Filters**: Search across your entire drive with instant filtering by name, extension, and media type.
- 📱 **Telegram-Themed Glassmorphic UI**: Sleek Telegram Web K/Z aesthetic with Telegram Drawer, Mirror View, and Quick Actions.
- 🔒 **Zero Third-Party Vendor Lock-in**: Your files stay in your own Telegram Saved Messages / Cloud.
- 🌐 **Single Port Architecture**: Unified access on port `5004` (Nginx/Vite automatically proxies `/api` requests to backend).

## 🚀 Quick Start

### Option 1: Docker (Recommended for Production & VPS)

Run the entire stack with a single command:

```bash
docker compose up -d --build
```

Access the application at: **`http://localhost:5004`**

To stop containers:
```bash
docker compose down
```

---

### Option 2: Local Development (pnpm)

1. **Install dependencies:**
   ```bash
   pnpm install
   ```

2. **Generate Database schema:**
   ```bash
   pnpm prisma:generate
   pnpm prisma:push
   ```

3. **Start local dev servers (Web on 5004 + Server on 5005):**
   ```bash
   pnpm run dev
   ```

4. Open **`http://localhost:5004`** in your browser.

## ⚙️ Environment Variables

Create a `.env` file in `apps/server/` or pass them via `docker-compose.yml`:

| Variable | Description | Default |
| :--- | :--- | :--- |
| `PORT` | Backend internal port | `5005` |
| `DATABASE_URL` | SQLite database file path | `file:./dev.db` |
| `REDIS_HOST` | Redis host | `localhost` / `redis` |
| `REDIS_PORT` | Redis port | `6379` |
| `JWT_SECRET` | Secret key for JWT session tokens (64-char random hex string) | Required |
| `TELEGRAM_API_ID` | Telegram API App ID from [my.telegram.org](https://my.telegram.org) | Required |
| `TELEGRAM_API_HASH` | Telegram API App Hash from [my.telegram.org](https://my.telegram.org) | Required |
